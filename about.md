About this software
===================

## markdownweb 0.0.6

- New package slug: slug.Of (the fragment identifier of one heading, GitHub's rule) and slug.Slugger (New, Next, Reset) for a whole page, where a repeated heading gets -1, -2, skipping any suffix already taken. For cmarkfind, cmarkbrowser's #fragment links and antennaApp's heading links.
- no other behaviour change

A Go module for the protocol layer of the Markdown web: fetch a page as Markdown (BonBon's Accept, the declared alternate link, the .md sibling), read a site's toc.opml and find a page's neighbours, browse a site on disk, and convert HTML to a Markdown reader view.
